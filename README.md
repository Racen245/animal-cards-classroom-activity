# Animal Cards Classroom Activity

Version 1.0.0

A real-time classroom web application that allows students to select one unique animal card from a shared set. The application synchronizes all devices using Firebase Realtime Database, ensuring that no two students can select the same animal.

## Features

- 🐾 One unique animal per student
- 🔄 Real-time synchronization with Firebase
- 📱 Responsive design for computers, tablets, and phones
- 💾 Student selection persists after page refresh
- 👀 Students can review their assigned animal card
- 👨‍🏫 Teacher can reset the activity for the entire class
- ⚡ Automatic updates across all connected devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Firebase Realtime Database

## How to Use

1. Open the application in a web browser.
2. Students select one available animal.
3. Each animal can only be assigned once.
4. Students can reopen their assigned card at any time.
5. The teacher can restart the activity using the reset button.
